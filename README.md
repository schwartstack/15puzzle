This project creates a fully playable [15-puzzle](https://en.wikipedia.org/wiki/15_puzzle), that runs in an R console session.

After running `play_15_puzzle()`, the user enters w, a, s, and d to move the moveable puzzle piece up, left, down, or right, respectively.

The puzzle is solved when the pieces are arranged in order from 1-15 with the empty space in the bottom right of the puzzle.
